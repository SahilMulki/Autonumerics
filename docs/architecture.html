Autonumerics · agent architecture

A differential equation goes in.
A verified solver comes out.

A multi-agent pipeline that reads a differential equation stated in plain English, designs several competing numerical schemes, implements and tests each one in parallel, and returns the winner — then submits its own answer to an independent check it cannot influence.

02 Design competing schemes, not one guess

Each plan is a self-contained brief: the scheme, its grid and step size, the stability condition it must respect, and the traps specific to it. Plans are deliberately differentiated — the pipeline is a search over methods, not a single attempt.

04 Select highest score, then fewest iterations
conductor

The orchestrator never touches the mathematics. It reads one field — the equation type — to route, dispatches every other agent, and keeps a durable ledger so an interrupted run resumes mid-cycle instead of starting over.

Independent

Everything above grades itself: the formulator writes down the exact solution, and the evaluator scores against it. That is circular — a formulator that transcribes the wrong exact solution still gets scored 10/10. So ground truth is authored separately, in a benchmark the agents never read, and the pipeline's answer is re-run against it.

Ground truth problems.py Written independently and cross-checked three ways: closed form, a discretization-free Monte Carlo reference, or — where no answer exists — the requirement that a correct scheme merely stays finite.
Re-run verify.py The winning solver.py is re-imported into a sandboxed subprocess — wall-clock timeout, memory cap, enforced import policy — and executed at a fixed step, path count and seed.
Verdict trust, but verify The pipeline's self-reported score is compared against the independent measurement. Agreement confirms it; disagreement is the finding that matters.

Baselines (a one-shot completion, and a single agent with tools) are graded by the same verifier, at the same step, path count and seed — so the comparison measures the structure, not the model.
